请使用 Three.js 创作一个主题为《时间的尽头》的 3D 交互式网页。
充分发挥你最顶级的审美、艺术设计和 3D 编程能力，在构图、光影、材质、粒子、动画和空间氛围上做到极致。画面需要有令人震撼的视觉表现力，并且可以通过鼠标自由交互。
不限制你的创意和技术方案，尽可能展示你的能力上限。请直接完成开发、运行和测试，交付一个真正可玩的作品。

交付要求
- 写入当前工作目录下的 `index.html`，单文件可直接运行。
- Three.js 必须是版本固定的 CDN module（如 `https://unpkg.com/three@0.169.0/build/three.module.js`），用 import map 加载；自己的 CSS 和 JS 全部内联。
- 无构建步骤、无本地资源文件、无外部模型或贴图，所有内容用代码生成。
- 1440 px 桌面和 390 px 手机宽度下都要可用、不越界。
- 可以用浏览器截图自测，但不要调用图像生成工具；没有验证的部分要如实说明。

重要：必须增量生成文件。先创建 HTML 骨架和样式，再分多次工具调用逐步追加
JavaScript、几何、材质、光照、粒子与交互逻辑；绝对不要尝试在一次工具调用里输出整个文件。
