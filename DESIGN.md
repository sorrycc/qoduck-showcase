# Design

## Theme

mono-print (from [frontend-rails](https://github.com/sorrycc/frontend-rails)) — picked 2026-11-09. Why: the gallery is a portfolio of colourful screenshots; a black-and-white Swiss-print frame with square corners and solid rules keeps every thumbnail the loudest thing on screen.

Page type: report (a showcase / comparison artifact), so the gate checks light and dark.

## Changed tokens

- None. `tokens.css` and `primitives.css` are the theme's files as shipped; page styles are in `page.css` and use only `var(--…)` tokens.
- Red (`--accent`) marks one thing: the "No follow-up." line in the hero, and the "With frontend-rails" side of each comparison pair.

## Rejected

- Nothing rejected by the user yet.
- Self-rejected: full-page PNG thumbnails in the gallery (1–3 MB each, ~40 MB total). The build crops each to a 960×600 `card.webp` instead.
- Self-rejected: `loading="lazy"` on cards. The cards are small enough to load eagerly, and lazy images show up blank in full-page gate screenshots.

## Accepted

- `.gate/1440.png`, `.gate/1440-dark.png` — hero with three stats, then comparison pairs, 3D scenes, and 2D pages separated by solid rules.

## Notes

- `index.html` is generated by `build-index.py`; edit the template there, not the HTML.
- Comparison pairs are found by the `-with-skill` / `-without-skill` folder suffix. "What the with-skill prompt adds" is a line diff of the two `prompt.md` files.
- A case goes under "3D scenes" when its HTML loads three.js or creates a WebGL context; everything else goes under "Illustration, SVG and pages".
- Card image URLs carry a content hash (`?v=`) because GitHub Pages serves `max-age=600`.
